# Universal Intelligence Engine — Commercial Handoff

## Product
A domain-agnostic intelligence runtime for research, reasoning, planning, evidence, tools, memory, evaluation, and controlled self-improvement.

## Included
- Provider-agnostic reasoning abstraction
- Evidence and provenance
- Planning and bounded autonomous replanning
- Controlled learning memory
- Native adaptive strategy selection
- Evaluation and regression gates
- Human-authorized governance
- HTTP API for domain adapters
- Automated tests

## Commercial positioning
The engine is the reusable intelligence layer. Domain applications can consume it without being rewritten when reasoning providers change.

## Verification
The default main branch has passing GitHub Actions runs through the current production baseline. Adaptive-learning work remains isolated until its CI is green.

## Buyer diligence
Verify provider credentials, production configuration, performance and cost, security, governance, IP ownership, third-party licences, and domain-specific validation.

## Safety boundary
Self-improvement proposes and evaluates changes; production activation remains behind explicit governance authorization. The engine does not silently rewrite production source code.

## Transfer
Any sale, licence, exclusivity, support, IP assignment, or future development must be defined in a written agreement.
