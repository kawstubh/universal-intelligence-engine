# Universal Intelligence Engine — Commercial Handoff

## Product
A domain-agnostic intelligence runtime for research, reasoning, planning, evidence, tools, memory, evaluation, and controlled self-improvement.

## Included
- Provider-agnostic reasoning abstraction
- Evidence and provenance
- Planning and bounded autonomous replanning
- Controlled learning memory
- Native adaptive strategy selection
- Evaluation and regression gates
- Human-authorized governance
- HTTP API for domain adapters
- Automated tests
- Sandboxed full-access self-improvement runtime

## Commercial positioning
The engine is the reusable intelligence layer. Domain applications can consume it without being rewritten when reasoning providers change.

## Self-improvement capability
Candidates receive broad source-development access inside disposable workspaces. The runtime can apply source changes, compile the project, execute the test suite, inspect the resulting diff, and run policy/security gates.

The candidate workspace has no production checkout, no repository remote, no credentials, and no promotion authority. Production activation remains a separate human-governed operation.

## Verification
The self-improvement runtime is isolated on a feature branch until CI is green. A candidate is not considered production-ready merely because its local gates pass.

## Buyer diligence
Verify provider credentials, production configuration, performance and cost, security, governance, IP ownership, third-party licences, and domain-specific validation.

## Safety boundary
Self-improvement may propose and evaluate aggressive source changes in a disposable workspace. It cannot silently rewrite production, alter governance, commit/deploy to production, or bypass the Ed25519 authorization gate.

## Transfer
Any sale, licence, exclusivity, support, IP assignment, or future development must be defined in a written agreement.
