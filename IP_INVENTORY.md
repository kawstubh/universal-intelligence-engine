# UIE Intellectual Property Inventory

## 1. Original UIE technology

The following categories are treated as project-owned original work for commercial packaging, subject to verification of contribution and assignment records:

- Core engine/orchestration
- Adaptive Reasoning Core (ARC)
- Evidence and provenance architecture
- Freshness and contradiction reasoning
- Planner and agent execution architecture
- Tool registry and capability policy
- Learning memory and evaluation framework
- Human governance and cryptographic authorization integration
- Self-improvement proposal/verification architecture
- Sandboxed self-improvement runtime
- HTTP API and application contracts
- UIE-specific tests and integration code
- UIE-specific deployment configuration and documentation

## 2. Downstream/domain IP

UIE is designed to support domain adapters. Dental, CueScene, and other application-specific implementations should be tracked separately so that ownership and licensing scope can be negotiated independently.

## 3. Third-party technology

Third-party packages are not claimed as UIE-owned IP. Their license obligations must be preserved. See `THIRD_PARTY_NOTICES.md`.

## 4. No patent claim

This inventory does not claim that any UIE feature is patented. Patentability, prior art, and filing strategy require a separate professional assessment.

## 5. Chain-of-title checklist

Before a transaction, verify:

- [ ] Rights-holder identity and contracting entity.
- [ ] All contributors identified.
- [ ] Contractor/employee IP assignments collected where applicable.
- [ ] No copied proprietary code from third parties.
- [ ] Third-party licenses reviewed.
- [ ] Secrets and credentials excluded from archives.
- [ ] Release commit and source archive hash recorded.
- [ ] Buyer scope tied to an exact version/snapshot.
- [ ] Any trademarks/domains/assets included in the transaction explicitly listed.

## 6. Evidence to preserve

Maintain dated copies of repository history, release archives, development records, design documents, issue history, test results, and signed contributor/assignment documents. These records help establish provenance but do not by themselves replace a legal chain-of-title review.
